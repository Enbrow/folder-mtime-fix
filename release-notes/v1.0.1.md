**FolderMTimeFix v1.0.1 — Tree-Grid 性能修复与交互体验改进。**

这是 v1.0.0 的维护更新，重点修复大型目录树的结果匹配性能、重新选择根目录后的排除规则，以及目录展开时的显示体验。文件夹时间修改规则保持不变。

## 修复与改进

- **大型目录树性能**：Tree-Grid 在关联目录处理结果和参考来源时，改为建立索引后一次遍历目录节点，避免每个文件和文件夹重复扫描全部处理结果。该步骤由原来的 O(节点数 × 目录结果数) 改为平均 O(节点数 + 目录结果数)。
- **切换根目录后的排除规则**：若将原先排除的子目录直接输入为新的根目录，程序会清除与新根目录相同的旧排除项，避免整棵目录树被意外跳过；真正位于新根目录下的其他排除项仍保留。
- **展开与收缩更跟手**：Tree-Grid 重建可见行后尽量保持原有顶部可见位置，不再轻易跳回最顶端。收起隐藏了顶部节点的父目录时，尝试定位仍可见的上级目录。
- **更清晰的展开状态**：保留经过实机测试的 `+`（未展开）和向下实心三角形 `▼`（已展开）。未展开时使用 Windows 系统文件夹图标；展开后绘制具有前翻盖的黄色打开文件夹，使两个状态在 Windows 11 上也能明显区分。

## 保持不变的行为

- **Dry Run** 仅计算预览，不修改文件时间。
- **Apply** 仅修改需要调整的目录 `LastWriteTime`；不修改文件内容、文件时间、创建时间或访问时间。
- 默认勾选“忽略直属子目录时间”：有直属文件时只参考最新直属文件；没有直属文件时仍参考最新直属子目录的处理后有效时间。
- 取消勾选后，将直属文件与直属子目录一起比较并使用最新时间。
- 排除目录不递归处理，但其当前目录时间仍可用于父目录的直属子目录参考。
- 忽略以 `.` 开头的项目以及 Junction、符号链接等 Reparse Point。
- 保留 Tree-Grid 的 GDI 密集点线、约 14 logical px 缩进、行颜色规则以及横向滚动和 Header 坐标的既有修复。

## 构建与测试

- GitHub Actions：Windows x64 / MSVC Release。
- 通过 CTest **3/3**：核心时间处理、Tree-Grid 结果匹配与排除规则、打开／闭合文件夹像素差异回归测试。
- 已完成人工 GUI 验收，包括展开／收缩符号及文件夹图标的辨识度。

## 下载与运行

请在本 Release 的 **Assets** 中下载 `FolderMTimeFix.exe`。它是面向 Windows x64 的独立可执行文件，不要求安装 PowerShell 或 .NET Runtime。

本版本不改变现有文件时间计算规则；建议先执行 Dry Run，确认结果后再选择 Apply。
