# FolderMTimeFix v1.0.0

**首个正式版本。**

FolderMTimeFix 是一个 Windows 原生 GUI 工具，用于根据目录中的直属内容恢复或修正文件夹的 `LastWriteTime`（“修改时间”）。

程序只在 Apply 模式下修改目录时间，不修改文件内容、文件时间、创建时间或访问时间。

## 主要功能

- **Dry Run 预览**：先扫描并计算即将修改的目录，不写入任何时间。
- **Apply 应用修改**：确认后才真正写入目录 `LastWriteTime`。
- **Tree-Grid 目录树**：
  - 按真实目录层级展开 / 收缩；
  - 使用 Windows Shell 文件 / 文件夹图标；
  - 显示大小、数量、类型、当前修改时间、即将修改时间和备注；
  - 支持多列排序，并始终保持目录优先。
- **清晰的状态标记**：
  - 黄色行：即将修改 / 已修改；
  - 蓝色行：本次时间计算使用的参考来源；
  - 灰色行：已排除目录。
- **参考来源提示**：需要修改的目录会在备注中显示实际参考的文件或子目录。
- **目录右键操作**：
  - 展开此目录及所有子目录；
  - 收缩此目录及所有子目录；
  - 排除 / 取消排除目录；
  - 刷新目录并重新执行 Dry Run。
- **可折叠面板**：右侧变更列表和底部详细日志都可收起，方便查看目录树。
- **日志功能**：显示详细处理结果，并支持复制 / 保存日志。
- **安全扫描**：忽略以 `.` 开头的项目（例如 `.git`），同时忽略 Junction、符号链接及其他 Reparse Point，避免误入其他目录树。

## 文件夹时间规则

默认勾选 **“忽略直属子目录时间”**：

- 当前目录存在直属文件时，只比较直属文件，使用最新直属文件的时间；
- 此时忽略直属子目录时间，避免子目录中的新文件逐级覆盖父目录；
- 当前目录没有直属文件时，仍使用最新直属子目录的处理后时间，因此纯目录层可以正常向上传递；
- 空目录保持原时间不变。

取消勾选后：

- 直属文件和直属子目录一起参与比较；
- 使用其中最新的时间作为当前目录的新修改时间。

子目录始终先于父目录处理，因此父目录比较到的是子目录处理完成后的有效时间。
